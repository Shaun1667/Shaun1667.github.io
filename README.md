# 포트폴리오 — Game Select

도트 감성 "게임 선택 화면" 포트폴리오. 내용은 전부 `data/games.js` 한 파일에서 고친다.

## 새 게임 추가
1. `games/<id>/` 폴더를 만들고 이미지 · 영상을 넣는다 (id = 영문 · 숫자 · 하이픈, 예: `steam-and-ink`).
   - `cover.jpg` — 대표 이미지 (16:9 권장)
   - `preview.mp4` — 고를 때 자동 재생되는 짧은 영상 (소리 없음, 5~10초, 수 MB 이하 권장)
   - `1.jpg`, `2.jpg` … — 스크린샷
2. `data/games.js`의 `GAMES` 목록에 `{ ... }` 하나를 추가한다 (기존 항목을 복사해서 고치면 편함).
   - 목록 순서 = 화면 순서. 최신작을 맨 앞에.
   - `theme` = 그 게임을 고르면 바뀌는 강조색.
   - `type` 값("개인" · "팀" · "회사" …)으로 위쪽 필터 탭이 자동으로 생긴다.
   - 빈 칸(`""`) · 빈 목록(`[]`)은 화면에서 숨겨진다. 이미지가 없으면 강조색 + 제목으로 대체 그림을 그린다.
   - `video`에는 YouTube 주소나 mp4 경로를 넣는다 (상세 페이지 맨 위).
3. 저장하고 새로고침. 끝.

## 상세 페이지 구성 (게임마다 같은 틀)
한 줄 소개 → 기간 · 인원 · 내 역할 · 기술 → 내가 한 일 → 문제 해결(퀘스트: 문제 · 해결 · 결과) → 스크린샷 → 링크 → 이전 · 다음 게임

## 조작
- ◀ ▶ (또는 A · D) 선택, Enter 시작, 1~9 바로 가기, P 프로필
- 상세 페이지에서 Esc · Backspace = 돌아가기
- SOUND 버튼: 8비트 효과음 (기본 꺼짐)

## 글꼴
- 도트: [Galmuri](https://github.com/quiple/galmuri) 2.40.3 (SIL 오픈 폰트 라이선스, jsDelivr에서 불러옴)
- 긴 설명: Noto Sans KR (Google Fonts)
- 도트 글꼴은 11px의 배수(11 · 22 · 33 · 44 · 66)에서 가장 또렷하다.
